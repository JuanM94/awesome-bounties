## How to Find Bounties

### GitHub Search Queries

```
# Algora bounties (real money, verified)
label:"💎 Bounty" state:open type:issue

# With dollar amounts
label:"💎 Bounty" label:"$100" state:open type:issue

# Opire bounties
"opire.dev" state:open type:issue

# General bounties with dollar amounts
label:bounty "$" state:open type:issue
```

### Tips for Claiming Bounties

1. **Read the issue carefully.** Meet ALL acceptance criteria.
2. **Comment before starting.** Some require `/attempt` or `/try` first.
3. **Check existing PRs.** Don't duplicate work.
4. **Quality > Speed.** Thorough READMEs and tests win.
5. **Follow the repo's contribution guide.**
6. **Include examples/screenshots** when applicable.
